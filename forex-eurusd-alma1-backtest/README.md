# EUR/USD ALMA-1 backtest research

This folder holds the requested search memory and rejected-threshold history for the 2-hour EUR/USD ALMA-1 analysis.

- `memoire_recherche.json` records the current search state and the best thresholds identified so far.
- `historique_rejets_ALMA-1.csv` records the distinct threshold rules tested and their best full-history result.

The uploaded market-data source is not copied into this folder.
